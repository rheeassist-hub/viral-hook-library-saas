# 🔥 Viral Hook Library SaaS (MVP)

크리에이터를 위한 **바이럴 훅(Hook) 문구 추천 SaaS**입니다.
숏폼 영상의 주제/카테고리를 입력하면, 사전에 축적된 한국어 바이럴 훅 패턴
데이터셋에서 매칭되는 훅 문구 5개를 즉시 추천해줍니다.

## 특징

- Python(FastAPI) + Jinja2 HTML 폼으로 구현된 실동작 웹앱
- 카테고리별로 분류된 하드코딩 훅 문구 데이터셋 (`hooks_data.py`)
- 정확 일치 → 부분 문자열 매칭 → 동의어/키워드 매핑 순으로 카테고리 검색
- 웹 폼(`/`, `/recommend`) 뿐 아니라 JSON API(`/api/recommend`)도 제공

## 프로젝트 구조

```
viral-hook-library-saas/
├── main.py            # FastAPI 앱 (라우팅)
├── hooks_data.py       # 하드코딩 훅 문구 데이터셋 + 추천 로직
├── templates/
│   └── index.html      # 입력 폼 + 결과 출력 화면
├── requirements.txt
└── README.md
```

## 하드코딩 훅 데이터셋 규모

총 **6개 카테고리 / 43개 훅 문구**

- 뷰티: 8개
- 재테크: 8개
- 반려동물: 8개
- 요리: 8개
- 운동/헬스: 8개
- 여행: 7개

각 문구는 '이거 아는 사람 없더라', '3초만 투자하면', '충격 결과',
'~하면 손해', '비밀 공개' 등 대표적인 한국어 숏폼 바이럴 훅 패턴을 기반으로 작성되었습니다.

## 설치 및 실행 방법

### 1. 의존성 설치

```bash
cd ~/dev/viral-hook-library-saas
pip3 install -r requirements.txt
```

### 2. 서버 실행

```bash
python3 -m uvicorn main:app --host 0.0.0.0 --port 8000
```

서버 실행 후 브라우저에서 `http://localhost:8000` 접속.

> 참고: 로컬 환경에서 8000번 포트가 이미 사용 중이라면 다른 포트(예: `--port 8010`)를 사용하세요.

## 사용법

1. 브라우저에서 웹앱 접속 (`http://localhost:8000`)
2. 입력창에 숏폼 영상 주제/카테고리 입력 (예: `뷰티`, `재테크`, `반려동물`, `요리`, `운동/헬스`, `여행`)
   - 지원 카테고리명이 아니어도 유사 키워드(`화장품`, `투자`, `강아지`, `다이어트` 등)로 자동 매칭 시도
3. "추천받기" 버튼 클릭
4. 매칭된 카테고리 이름과 함께 훅 문구 5개가 화면에 출력됨

### JSON API로도 사용 가능

```bash
curl -G "http://localhost:8000/api/recommend" --data-urlencode "category=뷰티"
```

## 데모 시나리오

### 시나리오 1: 뷰티 크리에이터

- 입력: `뷰티`
- 출력 (매칭 카테고리: 뷰티):
  1. 이거 모르고 화장하면 손해예요
  2. 피부과 원장님이 알려준 꿀팁, 이거 아는 사람 없더라
  3. 3초만 투자하면 피부 톤이 달라집니다
  4. 이 제품 안 쓰면 후회함... 진짜 충격 결과
  5. 다들 이 순서로 안 발라서 그런 거였어요

### 시나리오 2: 재테크 유튜버

- 입력: `재테크`
- 출력 (매칭 카테고리: 재테크):
  1. 이거 모르면 평생 돈 못 모읍니다
  2. 3초만 투자하면 통장 잔고가 달라져요
  3. 월급쟁이가 몰라서 못 하는 재테크 팁
  4. 이 앱 하나로 한 달에 30만원 아꼈습니다, 충격 결과
  5. 은행이 절대 알려주지 않는 이자 계산법

### 시나리오 3: 반려동물 채널 (동의어 매칭 예시)

- 입력: `강아지` (정확한 카테고리명은 "반려동물"이지만 동의어 매핑으로 자동 인식)
- 출력 (매칭 카테고리: 반려동물):
  1. 강아지가 이 행동하면 당장 병원 가세요
  2. 이거 모르고 사료 주면 큰일 납니다
  3. 수의사가 알려준 꿀팁, 이거 아는 사람 없더라
  4. 3초만 투자하면 고양이 마음을 알 수 있어요
  5. 반려동물 용품 이거 안 사면 후회합니다, 충격 결과

## 기술 스택

- Python 3.11
- FastAPI
- Uvicorn (ASGI 서버)
- Jinja2 (HTML 템플릿)

## 향후 확장 아이디어 (MVP 이후)

- 하드코딩 데이터셋 → DB(SQLite/PostgreSQL) 이전
- 사용자별 즐겨찾기/저장 기능
- LLM 기반 카테고리 밖 신규 훅 생성
- 훅 문구 성과(조회수/좋아요) 트래킹 연동
